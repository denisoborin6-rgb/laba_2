### Задание 1. Имена

Текст задания.

Создайте сущность Имя, которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трёх параметров: «Фамилия Имя Отчество» (например, «Иванов Иван Иванович»). Необходимо предусмотреть возможность того, что какой-либо из параметров может быть не задан, и в этом случае он не учитывается при приведении к текстовому виду.

Необходимо создать следующие имена:

Клеопатра

Пушкин Александр Сергеевич

Маяковский Владимир

Обратите внимание, что при выводе на экран не заданные параметры никак не участвуют в образовании строки.

## Алгоритм решения.

Создать класс Task1 с тремя приватными полями: surname, firstName, patronymic.

Реализовать вспомогательный метод normalize(String), который приводит null, пустые строки и строки из пробелов к единому значению null. Это позволяет трактовать «не задано» одинаково во всех случаях и упрощает проверки.

Реализовать несколько конструкторов (перегрузка):

Task1(surname, firstName, patronymic) — все три параметра;

Task1(surname, firstName) — без отчества;

Task1(firstName) — только личное имя;

Task1() — пустой.
Каждый конструктор при необходимости вызывает другой через this(...), чтобы не дублировать код.

Переопределить метод toString(): с помощью StringBuilder собрать строку только из заданных частей, добавляя пробел лишь между реально существующими частями.

Реализовать статический метод run(), который создаёт три заданных имени, собирает их в одну строку через StringBuilder и возвращает её. Никакого вывода внутри метода нет — вывод перенесён в Main.

В классе Main при выборе соответствующего пункта меню печатается заголовок задания и результат вызова Task1.run().

Человека с именем Клеопатра и ростом 152;

### Задание 3. Человек с родителем

Текст задания.

Измените сущность Человек из задачи 2.2, добавив ему возможность задавать третий параметр: Отец, где Отец — это тоже Человек. При приведении человека к строковой форме необходимо проверить параметры имени и в зависимости от ситуации выполнить одно из следующих действий:

Если у данного человека нет фамилии, и есть отец, у которого фамилия задана, то фамилию необходимо сделать такой же, как у отца.

Если у данного человека нет отчества, а у отца есть имя, то необходимо задать отчество как имя отца с добавлением суффикса «ович».

Затем необходимо выполнить следующие задачи:

Создать людей: Чудова Ивана, Чудова Петра, Бориса.

Сделать Ивана отцом Петра, а Петра — отцом Бориса.

Вывести на экран строковое представление всех трёх людей.

## Алгоритм решения.

Создать класс Task3 с тремя приватными полями:

name — объект Task1;

height — целое число;

father — ссылка на объект Task3 (отец — тоже человек).

Task3(name, height) — без отца;

Task3(name, height, father) — с отцом.

Реализовать вспомогательные методы:

resolveSurname() — возвращает собственную фамилию, если она задана, иначе фамилию отца (если она задана), иначе null;

resolvePatronymic() — возвращает собственное отчество, если оно задано, иначе «имя отца + ович», иначе null.
Эти методы вычисляют значения динамически, а не хранят их в полях.

Переопределить toString(): собрать строку из эффективных фамилии, имени и отчества, добавить «, рост N».

Реализовать статический метод run(): создать Бориса без отца, Петра с отцом Борисом, Ивана с отцом Петром; собрать результаты в строку и вернуть её. Вывод в методе отсутствует.

В классе Main печатается заголовок и результат Task3.run().


### Задание 4. Ломаная

Текст задания.

Создайте сущность Ломаная, которая будет представлять собой ломаную линию. Ломаная линия представляет собой набор следующих характеристик:

Имеет массив Точек (из задачи 1.1), через которые линия проходит.

Может быть приведена к строковой форме вида «Линия [T1,T2,...,TN]», где TN — это результат приведения к строке Точки с номером N.

Необходимо выполнить следующие задачи:

Создать первую Ломаную, проходящую через точки (1;5), (2;8), (5;3).

Создать вторую Ломаную, чья первая и последняя Точка совпадает с таковыми у первой Ломаной, но в качестве середины имеет точки: (2;-5), (4;-8).

Сдвинуть начало первой Ломаной таким образом, чтобы одновременно сдвинулось начало второй Ломаной.

## Алгоритм решения.

Внутри класса Task4 объявить два вложенных статических класса:

Point — точка с полями x и y, конструкторами, методом shift(dx, dy) и методом toString() вида «(x;y)»;

Polyline — ломаная с полем points типа Point[], конструкторами (пустой и с varargs), методами getPoints, getPoint, toString() вида «Линия [T1,T2,...,TN]».

Метод shift(dx, dy) прибавляет к текущим координатам точки значения dx и dy, изменяя сам объект, а не создавая новый.

В статическом методе run():

создать общие точки p1 и p3;

построить first = (p1, p2, p3);

построить second = (p1, p4, p5, p3) — те же p1 и p3, что и в первой ломаной, а p4 и p5 — новые точки;

собрать в строку представление обеих ломаных;

вызвать first.getPoint(0).shift(10, 10) — изменяется сам объект p1, поэтому изменение видно и во второй ломаной;

добавить в строку обновлённые представления обеих ломаных и вернуть результат.

Вывод в run() отсутствует — он перенесён в Main.

Пояснение. Изменение объекта p1 через метод shift() видно обеим ломаным, потому что они хранят ссылку на один и тот же объект, а не копии.

### Задание 6. Длина ломаной

Текст задания.

Измените сущность Ломаная из задачи 4.9. Новые требования включают:

В любой момент к имеющимся Точкам можно добавить новые Точки (добавляется либо массив, либо просто перечень точек, что приводит к получению нового массива, содержащего как старые, так и новые значения).

Может возвращать общую длину ломаной.

Необходимо выполнить следующие задачи:

Создать Ломаную, проходящую через точки (1;5), (2;8), (5;3).

Вывести на экран её длину.

Добавить (к ранее созданной Ломаной) точки (5;15), (8;10).

Снова вывести на экран длину Ломаной.

## Алгоритм решения.

В класс Task4.Polyline добавить:

метод addPoints(Point... newPoints): создаёт новый массив длиной «старый + новые», копирует туда старые точки через System.arraycopy, затем новые, и заменяет поле points ссылкой на новый массив. Это нужно, потому что длина массива в Java фиксирована;

метод length(): проходит по всем парам соседних точек и складывает длины звеньев по теореме Пифагора — для каждого звена вычисляется sqrt(dx в квадрате + dy в квадрате).

Создать класс Task6 с приватным полем line — ломаная, созданная из точек (1;5), (2;8), (5;3).

Реализовать метод length(), делегирующий вызов в line.length().

Переопределить toString() — возвращает «Task6: <строка ломаной>».

Реализовать статический метод run():

вывести в строку ломаную и её длину (округлённо до 3 знаков через String.format);

добавить точки (5;15) и (8;10) через addPoints;

добавить в строку новую ломаную и новую длину;

вернуть результат.

Вывод в run() отсутствует — он перенесён в Main.

Формула длины ломаной: сумма по всем соседним парам точек от квадратного корня из ((x(i+1) минус x(i)) в квадрате плюс (y(i+1) минус y(i)) в квадрате).

### Класс Main. Общий алгоритм программы

Проект содержит 7 классов: 6 классов-задач (Task1 … Task6) и один класс Main с точкой входа.

Каждый класс-задача имеет:

свойства (приватные поля);

конструкторы (в том числе перегруженные);

переопределённый метод toString();

статический метод run(), который выполняет логику задания, собирает результат в StringBuilder и возвращает готовую строку, не печатая её.

Класс Main содержит:

меню с пунктами 1–6 и 0 (выход);

метод readInt() с проверкой ввода: если пользователь ввёл не число, программа не падает, а просит повторить;

весь вывод на экран: перед вызовом задачи печатается её заголовок, затем — результат TaskN.run().

Данные во всех задачах заранее известны и заданы в коде — ввод с клавиатуры используется только для выбора пункта меню.
